# Headless regression tests

Production code is compiled directly from `../src/*.cs`. Tests execute real Harmony patches against the complete Rough Seas v5.0.1 tagged C# source and an actual Rivers 5.0.3 DLL. Game assemblies, Rivers binaries and generated upstream fixtures are not committed or redistributed by this repository.

## Prerequisites

- Python 3, Git, .NET SDK 10, and network access for NuGet packages.
- A local Vintage Story 1.22.7 installation containing `VintagestoryAPI.dll`, `VintagestoryLib.dll`, `Lib/0Harmony.dll` and `Mods/` assemblies. This is the tested API version; other versions are not verified.
- A local checkout of `https://github.com/hoblin/rough-seas` with tag `v5.0.1` fetched.
- `Rivers.dll` extracted from the Rivers 5.0.3 mod ZIP.

From the repository root, set absolute dependency paths appropriate for your machine:

```sh
export VINTAGE_STORY_DIR=/absolute/path/to/vintagestory
export ROUGH_SEAS_REPO=/absolute/path/to/rough-seas
export RIVERS_DLL=/absolute/path/to/Rivers.dll
# If dotnet is not on PATH:
export DOTNET_ROOT=/absolute/path/to/dotnet-sdk

python3 tests/setup.py
python3 tests/run.py
python3 tests/run-currents.py
python3 package.py
```

Setup generates ignored project files and copies every upstream C#/JSON file verbatim from the tag; the core runner verifies the entire fixture manifest and bytes before building. Runners never modify production sources. Results are written to ignored `tests/results.txt` and `tests/currents-results.txt`. The source/test ZIP generated by `package.py` includes local upstream fixtures; inspect licensing before redistributing that development archive.

## Coverage and limits

- Core: 170 assertions, with log/hull/power patch-removal negative controls.
- Currents/player flow: 65 assertions and 2,000 seeded projection cases, with four negative controls.
- Composite Rough Seas current → hull integration → actual Rivers boat postfix, player-current opt-out/opt-in, nonplayer behavior and vanilla liquid-physics continuation are exercised.
- Expected negative-control processes exit nonzero; the runner succeeds only when they fail at the intended assertion and the final unmodified production run passes.
- `red-1.6-results.txt` preserves the historical unsupported-version regression before the 1.7 port.

These are headless tests with mocked game interfaces and deterministic sea sampling—not a saved-world, rendering, multiplayer, complete swimming-physics or full tick-loop test. The vanilla DoApply continuation check reaches the real block query with `Swimming=false`; it does not prove the full HandleSwimming path.
